# MConnect

Плагин для прослушивания звука из DAW на телефоне через QR-код. Производный от
[PGStream](https://github.com/Andrulius/PGStream), с интерфейсом MConnect и
переносимой сборкой. Лицензия AGPL-3.0-only; см. NOTICE.md.

[Скачать установщик для macOS](https://github.com/ibotpafos/MConnect/releases/latest)
· [Все релизы и исходники](https://github.com/ibotpafos/MConnect/releases).

## Использование

1. Установите AU или VST3 и пересканируйте плагины в DAW.
2. Поставьте MConnect последним на Master Bus или Listen Bus.
3. Подключите телефон и компьютер к одной локальной сети.
4. Откройте плагин, отсканируйте QR-код, нажмите «Слушать» в браузере.
Страница подключается заранее; если браузер разрешает автоматическое
воспроизведение, звук включается сам. На iPhone обычно нужно одно нажатие
«Слушать». Это ограничение браузера. Громкость меняется кнопками телефона.

Плагин всегда пропускает исходный сигнал DAW без изменений и без добавленной
задержки. QR-код ведёт на сервер внутри плагина. Режим — стерео Opus 48 kHz,
320 kbps; до четырёх слушателей. Это сжатие с потерями, а задержка
на телефоне зависит от браузера, сети и Bluetooth. Закрытие окна плагина не
останавливает передачу; кнопка Stop останавливает. В плагине только QR, статус,
Start/Stop, Copy link и номер версии. Сеть, свободный порт, ресемплинг и буфер выбираются
автоматически. Страница сама восстанавливает кратковременно оборванное соединение.

Без слушателей захват и кодирование аудио отключены. Когда окно закрыто,
индикаторы также не рассчитываются. Кодирование и сеть работают в отдельном
потоке: блокировок, выделения памяти и сетевых операций в аудиоколбэке нет.

## Установка на macOS

Откройте `dist/MConnect-0.1.5-macos-universal.pkg` двойным щелчком и пройдите
шаги обычного macOS Installer. Файл можно переслать другу целиком. Нужна macOS 11
или новее; AU и VST3 содержат Apple Silicon и Intel. Плагины устанавливаются
для текущего пользователя и при обновлении заменяются в тех же папках.
Перед установкой закройте DAW; после установки при необходимости пересканируйте плагины.

Текущая сборка использует ad-hoc подпись плагинов, без Developer ID и
нотарификации. При открытии полученного через интернет файла macOS может
потребовать разрешение. Порядок действий, пути установки и удаление:
[docs/INSTALL.md](docs/INSTALL.md).

Для ручной установки остаётся `dist/MConnect-0.1.5-macos-universal.zip`
с `Install.command`. Старый скрипт сохраняет предыдущие версии как `.backup-*`;
обычный `.pkg` обновляет пакеты на месте.

## Обновления

Начиная с 0.1.5 обновлениями управляет GD Connect. Он проверяет GitHub Releases,
показывает доступные версии и устанавливает AU/VST3 из проверенного ZIP. Перед
установкой сохраните проект и закройте DAW. Сам MConnect не проверяет релизы
и не скачивает установщики; внизу окна остаётся только номер версии.

GD Connect не нужен для передачи звука. Отдельный `.pkg` и ZIP остаются
доступны для ручной установки. Переход со старых 0.1.3/0.1.4 возможен через
их кнопку обновления или через менеджер. Подробнее: [docs/UPDATES.md](docs/UPDATES.md).

## Сборка

Нужны Git, Python 3.9+, CMake 3.22+, C/C++ toolchain. На macOS достаточно Xcode
Command Line Tools; на Windows — Visual Studio с Desktop development with C++.

```sh
python3 scripts/bootstrap.py
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel 6
ctest --test-dir build -C Release --output-on-failure
```

Universal macOS (Apple Silicon + Intel): добавьте на шаге configure
`-DCMAKE_OSX_ARCHITECTURES="arm64;x86_64"`. Артефакты —
`build/MConnect_artefacts/Release/`: AU и VST3. Отдельного приложения для телефона
или компьютера в поставке нет; тестовый хост используется только при разработке.
Windows — VST3; Linux — VST3/LV2 (нужны JUCE system development dependencies).
AAX для Pro Tools требует отдельного SDK и здесь не включён.

После сборки universal-плагинов создайте установщик:

```sh
python3 scripts/package_macos.py build
python3 tests/installer.py dist/MConnect-0.1.5-macos-universal.pkg
```

Скрипты сборки и установщика, все исходники, закреплённые версии зависимостей
и лицензии находятся в Git. `build/`, `external/`, `dist/`, результаты тестов
и закрытые ключи исключены. История версий: [CHANGELOG.md](CHANGELOG.md).

## Если нет соединения

- Проверьте, что DAW разрешён доступ к локальной сети и входящим соединениям.
- Не используйте гостевую Wi-Fi сеть с изоляцией клиентов. При проблемах с VPN
  отключите его для локальной проверки. Адрес физической сети выбирается автоматически.
- При нескольких экземплярах порты выбираются автоматически, начиная с 8123.
- Если нет звука: запустите транспорт DAW, проверьте уровни в плагине и громкость
  телефона, затем нажмите «Слушать» в браузере. Некоторые DAW при остановке не вызывают
  аудиообработку; сервер поддерживает соединение пакетами тишины.
- Используйте актуальный Safari на iOS или Chrome на Android. Фоновые вкладки и
  заблокированный экран могут приостанавливать воспроизведение.
- Работа рассчитана на доверенную локальную сеть. HTTP-страница/сигналинг не
  шифруются, аудиопоток WebRTC шифруется. Ссылка содержит ключ подключения;
  следующий экземпляр плагина создаёт другой ключ. Не делайте проброс портов.

Сборка и тесты на этом Mac не означают проверку на всех DAW/телефонах.
