# Установка MConnect на macOS

## Установщик

Файл `MConnect-0.1.4-macos-universal.pkg` можно переслать целиком. Он содержит
AU и VST3 для Apple Silicon и Intel; минимальная версия системы — macOS 11.
На телефоне используется браузер: Safari на iOS или Chrome на Android.

1. Закройте DAW перед установкой или обновлением плагина.
2. Откройте `.pkg` двойным щелчком: «Продолжить» → «Установить» → «Закрыть».
3. Откройте DAW и пересканируйте плагины, если MConnect ещё не появился.
4. Поставьте MConnect последним на Master Bus или Listen Bus, подключите телефон
   к той же сети, отсканируйте QR-код и нажмите «Слушать».

Установка выполняется для текущего пользователя. Другим пользователям Mac
нужно открыть установщик в своей учётной записи. Папки назначения:

- `~/Library/Audio/Plug-Ins/Components/MConnect.component`
- `~/Library/Audio/Plug-Ins/VST3/MConnect.vst3`
- `~/Library/Application Support/MConnect/` — инструкция, лицензии и исходники.

Обновление заменяет прежние пакеты целиком в тех же папках. Перемещённые
копии и резервные копии не используются как место установки. Версия плагина,
которая новее установщика, защищена от перезаписи. Плагины, установленные
старым `Install.command`, обновляются в тех же местах; уже существующие
`.backup-*` остаются на диске. Перезагрузка Mac не нужна.

## Если macOS блокирует файл

Текущая локальная сборка использует ad-hoc подпись плагинов. Установщик не
подписан Developer ID Installer и не нотарифицирован Apple. Поэтому файл,
полученный через интернет, может потребовать ручного разрешения.

После попытки открыть проверенный файл перейдите в «Системные настройки» →
«Конфиденциальность и безопасность», найдите сообщение о MConnect и нажмите
«Всё равно открыть» / Open Anyway. Подтвердите действие, если macOS попросит.
Подробности: [инструкция Apple](https://support.apple.com/en-us/102445).

Автоматический запуск на любом чужом Mac без предупреждений требует
Developer ID Application для плагинов, Developer ID Installer для `.pkg`
и нотарификации. Установщик не изменяет настройки Gatekeeper.

## Удаление

Закройте DAW и удалите только `MConnect.component` и `MConnect.vst3` из
указанных выше папок. Документацию в `~/Library/Application Support/MConnect/`
можно удалить отдельно. Другие плагины и проекты не затрагиваются.

## Сборка установщика из исходников

После сборки universal AU/VST3 выполните:

```sh
python3 scripts/package_macos.py build
python3 tests/installer.py dist/MConnect-0.1.4-macos-universal.pkg
```

Для проверки реальной установки и повторного обновления на своём Mac добавьте
к последней команде `--install`. Эта проверка устанавливает плагины в текущую
учётную запись; запуск DAW не нужен. Без флага проверяется только содержимое
и конфигурация пакета.

Скрипт использует штатные `codesign`, `pkgbuild` и `productbuild`, проверяет
версии, обе архитектуры, подписи и актуальность архива исходников. Создаёт
`.pkg`, прежний ZIP для ручной установки и файл SHA-256 в `dist/`.

Для сборки с уже настроенными сертификатами:

```sh
python3 scripts/package_macos.py build \
  --application-identity 'Developer ID Application: YOUR NAME (TEAMID)' \
  --installer-identity 'Developer ID Installer: YOUR NAME (TEAMID)'
```

Подпись не выполняет нотарификацию. Перед публичной поставкой отправьте
подписанный `.pkg` в Apple через `xcrun notarytool submit` с вашим профилем
Keychain, дождитесь статуса Accepted, затем выполните `xcrun stapler staple`
и `xcrun stapler validate`. После stapling пересчитайте SHA-256. Секреты,
сертификаты с закрытым ключом и файлы сборки не входят в Git-репозиторий.
Основание: [документация Apple по нотарификации](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution).
