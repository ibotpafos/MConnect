# Обновления MConnect через GD Connect

Начиная с 0.1.5 управление версиями находится в GD Connect. Менеджер проверяет
стабильные релизы GitHub, показывает обновления и устанавливает AU/VST3 из ZIP.
В плагине остаётся обычный номер версии: проверки релизов, загрузки, кеш
обновлений, рабочий поток и окна Installer удалены из его исполняемого кода.
Перед заменой плагинов сохраните проект и закройте DAW.

Текущий GD Connect автоматически проверяет релизы при запуске с интервалом
не менее шести часов; установка выполняется по действию пользователя. Решения
об автоматизации установки относятся к менеджеру. Плагин не требует запущенного
GD Connect для передачи звука, доступа к интернету или аккаунта.

## Совместимость с менеджером

Сохраняется контракт пакета для GD Connect:

- Основной канал менеджера задаётся его каталогом. Для общего канала
  `ibotpafos/GD-Connect-Releases` версия MConnect, URL, размер, SHA-256 и тег
  должны быть внесены в новый каталог релиза.
- Отдельный репозиторий `ibotpafos/MConnect` и стабильный тег `vX.Y.Z`
  сохраняются для ручных загрузок и перехода со старого updater.
- Архив: `MConnect-X.Y.Z-macos-universal.zip`, с AU и VST3 внутри.
- Пакеты: `MConnect.component` и `MConnect.vst3`.
- Bundle ID: `audio.mconnect.plugin`; версия — `CFBundleShortVersionString`.
- macOS 11+, архитектуры `arm64` и `x86_64`.
- Размер и SHA-256 архива публикуются в метаданных релиза. Менеджер проверяет
  их перед распаковкой и проверяет версии, идентификаторы и подписи пакетов.

GD Connect устанавливает пакеты сам и не запускает `Install.command` из ZIP.
Не меняйте имена архивов или bundle ID без изменения каталога.
Настройка `MCONNECT_RELEASE_REPOSITORY` нужна инструменту публикации;
адрес репозитория не передаётся в исполняемый код плагина.

## Переход с 0.1.3 и 0.1.4

Старые версии содержат встроенное обновление. Для переходного релиза остаётся
`.pkg` с прежним именем `MConnect-X.Y.Z-macos-universal.pkg` и digest SHA-256
в GitHub Releases. Старый клиент сможет предложить его обычным способом;
после установки 0.1.5 строка обновлений исчезнет. Также можно установить версию
через GD Connect или вручную. Уже опубликованные теги и файлы не заменяются.

Старый кеш `~/Library/Caches/MConnect/Updates/` больше не используется.
Его можно удалить вручную при закрытой DAW. Новая версия не удаляет данные
предыдущего клиента автоматически.

## Ручная установка

Отдельные `.pkg` и ZIP остаются доступны тем, кто не использует менеджер.
Пути и порядок установки описаны в [INSTALL.md](INSTALL.md). Подпись Developer
ID и нотарификация — отдельные свойства поставки; перенос обновлений в менеджер
не меняет статус доверия macOS.

## Подготовка и публикация релиза

1. Измените `project(MConnect VERSION …)` и добавьте запись в `CHANGELOG.md`.
2. Соберите universal AU/VST3, выполните тесты и создайте пакет:

   ```sh
   bash scripts/build.sh
   python3 scripts/package_macos.py build
   python3 scripts/release_github.py
   ```

3. Последняя команда локально проверяет пакет и SHA-256, показывает файлы,
   репозиторий, тег и текст релиза. Загрузки и публикации она не выполняет.
4. После проверки подготовьте черновик:

   ```sh
   python3 scripts/release_github.py --upload-draft
   ```

5. Для публикации проверенного релиза:

   ```sh
   python3 scripts/release_github.py --publish
   ```

Скрипт отправляет только чистую ветку `main`, проверяет соответствие `origin`
репозиторию релизов, создаёт неизменяемый тег `vX.Y.Z`, загружает `.pkg`, ZIP,
исходники и SHA-256. До публикации сверяет GitHub digest каждого файла;
опубликованные релизы не перезаписывает. Черновик проверяется и публикуется
по числовому ID. Этот скрипт публикует отдельный релиз MConnect; каталог
общего канала GD Connect он не меняет. Чтобы версия появилась в менеджере,
добавьте этот проверенный ZIP и его метаданные в новый релиз общего канала
через инструменты публикации GD Connect. Не заменяйте уже опубликованный
каталог или ZIP. До такой публикации менеджер предлагает прежнюю версию.

Для другого отдельного репозитория измените default
`MCONNECT_RELEASE_REPOSITORY`. Адрес общего канала задаётся в GD Connect.

Проверки текущей версии: [VALIDATION.md](VALIDATION.md).
Историческая проверка встроенного обновления 0.1.4:
[VALIDATION_0.1.4.md](VALIDATION_0.1.4.md).
