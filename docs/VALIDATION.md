# Проверка MConnect 0.1.5 — 2026-10-18

Среда: macOS 26.6.2, Apple Silicon, universal arm64+x86_64. DAW не запускалась.
Использованы программный источник, отдельный редактор, реальные Chromium/WebKit,
pluginval 1.0.4 и тестовый CLI GD Connect. Пользовательские плагины не заменялись.

## Изменение

Обновления переданы GD Connect. Из исполняемого кода удалены updater, его
HTTPS-транспорт, фоновые проверки/загрузки и окна установки. В редакторе
остаётся обычная версия. Аудиопроцессор, состояние, FIFO, сетевой сервер,
кодек, ресемплер и телефонная страница побайтно совпадают с предыдущим HEAD
`8424ac5`; их поведение повторно проверено после пересборки.

Сохранены bundle ID `audio.mconnect.plugin`, plugin codes, параметры, формат
состояния, имена AU/VST3 и формат universal ZIP для менеджера. PKG остаётся
для ручной установки и перехода со встроенного updater старых 0.1.3/0.1.4.

## Исправленная совместимость macOS

У первого кандидата обнаружено расхождение: установщик обещал macOS 11,
но обе архитектуры бинарников имели `minos 26.0`. Пустая запись
`CMAKE_OSX_DEPLOYMENT_TARGET` в кеше переживала обычный default `set(... CACHE)`.
CMake теперь заменяет пустое значение на 11.0, штатный build.sh задаёт его явно.
Пакетировщик и тест Installer проверяют `LC_BUILD_VERSION` обеих архитектур.
Оба новых ограничения проверены на реальном несовместимом кандидате: отказ
до установки. Этот кандидат перемещён из dist в отдельную папку результатов.

Пересборка с исходным пустым кешем выставила 11.0. `vtool -show-build`
подтверждает `minos 11.0` для arm64 и x86_64 в AU и VST3. Все описанные ниже
проверки выполнения повторены после изменения deployment target. Это проверка
метаданных и работы на текущей системе; отдельного запуска на macOS 11 не было.

## Автоматические проверки

- Release CTest: core, editor, release_tool — PASS; release_tool содержит шесть
  регрессий поиска/публикации черновиков и проверки digest.
- Core и редактор под Rosetta x86_64 — PASS.
- Битовый passthrough float/double, bypass/offline, mono/state, конкурентное
  переполнение FIFO, стерео SRC и подавление aliasing — PASS.
- Восемь открытий/закрытий редактора, границы элементов и снимок — PASS.
- HTTP/WebSocket pairing, Origin, исходники/лицензия, некорректный и глубокий
  JSON, типы, фрагменты, binary/oversized frames, освобождение слотов — PASS.
- Семь реальных браузерных сценариев: Chromium при 44.1/48/96/192 kHz и
  блоках 256/1024/2048; WebKit при 48 kHz/256 — PASS. Проверены декодирование
  разных тонов L/R, отсутствие смешивания каналов, autoplay fallback,
  неправильный pairing key и автоматическое восстановление соединения.
- Четыре слушателя и восстановление пятого при освобождении слота, адаптация
  буфера к loss/concealment и последующее снижение, page-cache restore,
  устаревшее pause-событие, длинный обрыв, смена частот на ходу, тишина при
  остановке источника и нормальное завершение с активным слушателем — PASS.
- VST3 pluginval 1.0.4: strictness 10, 48/192 kHz × 256/2048, repeat 2,
  seed 101805 — SUCCESS.

## Упаковка и менеджер

ZIP исправленной сборки прошёл установку, повторную замену и удаление AU/VST3
через нативный gdconnect-check в новых песочницах на D. Проверены размер,
SHA-256, идентификаторы, версии, архитектуры и ad-hoc подписи. Проверены
метаданные общего канала GD Connect и отдельного репозитория MConnect.
Обновление с синтетических метаданных версии 0.0.0 прошло; это не прогон
настоящего старого бинарника. Неправильный SHA-256 отклонён до установки,
пакетов AU/VST3 после отказа нет.

В обеих архитектурах упакованных AU/VST3 подтверждены минимум macOS 11 и
отсутствие символов mconnect::updates и адреса API проверки релизов. Вложенный
архив исходников не содержит удалённых updater/transport и их тестовых целей.

Структура PKG проверяется tests/installer.py без `--install`: домен текущего
пользователя, отдельные receipts AU/VST3/документации, версии, минимум ОС,
подписи, актуальность вложенных исходников, лицензии и локализация. Сам PKG
в пользовательскую учётную запись в этой задаче не устанавливается.

Локальные логи: `output/gd-connect-updates/`. Нативный CLI менеджера скопирован
для воспроизводимости; SHA-256
`bbe2ffd8af96524c11c9f21eb62ec605d1640c91246fc90c6404a106e132903c`.
Копия каталога для проверки локальная; тест не публикует релиз и не выдаётся
за проверку появления новой версии через публичный канал GitHub.

## Ограничения

Публичные 0.1.3/0.1.4 не заменялись; релиз 0.1.5 ещё не опубликован в рамках
этой проверки. Версия появится в GD Connect после выпуска его нового каталога.
Подпись Developer ID и нотарификация не добавлялись. Физические iPhone/Android,
другие DAW, Windows/Linux и macOS 11 отдельно в этом прогоне не проверялись.
Санитайзеры для 0.1.5 повторно не запускались; старые результаты не выдаются
за новый прогон. Предыдущая успешная студийная проверка сообщена пользователем.
