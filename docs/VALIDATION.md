# Проверка MConnect 0.1.3 — 2026-10-14–15

Среда: macOS 26.6.2, Apple Silicon, Apple Clang 21.0.0. Основная сборка —
universal arm64+x86_64, минимальная система macOS 11. DAW не запускалась:
использованы программный источник, браузеры, pluginval и системный auval.

Для сетевой проверки скачан публичный `pluginval_macOS.zip` 1.0.4 с GitHub.
Его байты, размер и SHA-256 сравнены с независимой загрузкой curl. Это
проверка настоящего системного транспорта с перенаправлением на CDN.
Цепочка обнаружения релиза, проверки digest, загрузки и повторного открытия
кеша дополнительно проверена контролируемым транспортом без публикации
фиктивного релиза в интернете.

Снимок редактора: `output/updates/editor.png` (локальный артефакт).
В финальных санитайзерных прогонах максимальное закрытие окна заняло около
66 ms; ранние прогоны с кешем — около 2.6 ms. Это наблюдение конкретного Mac,
не гарантия времени для всех систем.

## Память и потоки

ASan+UBSan и TSan собраны отдельно с инструментированием C, C++ и
Objective-C++. `core` и `updates` проходят в обеих сборках. Дополнительно
в каждой проверены настоящий HTTPS, отмена, нативная загрузка бинарного
файла и 8 переоткрытий редактора. Ошибок санитайзеров нет, подавления
предупреждений санитайзеров не добавлялись. LeakSanitizer выключен
(`detect_leaks=0`); это не проверка всех утечек системных framework.

Процессор, аудиоколбэк, WebRTC sender и телефонная страница побайтно
совпадают с 0.1.2. Обновления принадлежат только открытому редактору.
Проверка сети и SHA-256 выполняется рабочим потоком низкого приоритета;
после закрытия последнего окна этот поток и запрос завершаются.

## Совместимость и передача звука

VST3 прошёл pluginval 1.0.4 strictness 10, два случайных повтора, seed 101403:
32/44.1/48/96/192 kHz × блоки 1/64/256/2048/8192. Включены проверки редактора,
состояния и автоматизации. Результат `SUCCESS`.
После исправления повторной проверки установщика strictness 10 повторён
на 48/192 kHz и блоках 256/2048 с seed 101503 — `SUCCESS`.

Матрица из семи браузерных сценариев — PASS: Chromium и WebKit при 48 kHz,
Chromium при 44.1/96/192 kHz, а также блоки 1024 и 2048 при 48 kHz. Проверен
реально декодированный стереосигнал, autoplay fallback, отказ неправильному
ключу, автоматическое восстановление и три ручных переподключения.

Сценарий устойчивости — PASS: четыре слушателя, освобождение пятого слота,
адаптация буфера при потерях и concealment, возврат страницы из кеша,
восстановление после восьмисекундного отключения, живые переключения
192/44.1/48 kHz, блок 2048, тишина при остановке источника и штатное
завершение с активными клиентами. Порог проверки стереозвука сохранён.

Полный предыдущий аудит, включая 10-минутный прогон четырёх слушателей,
измерения CPU и маршрутизации LAN, находится в
[VALIDATION_0.1.2.md](VALIDATION_0.1.2.md). Эти длительные и CPU-измерения
относятся к 0.1.2; в 0.1.3 они не повторялись.

## Установщик и публикация

Проверены обе архитектуры AU/VST3, подписи, установка для текущего пользователя,
соответствие исходников и лицензии. Первичная и повторная установка 0.1.3
прошли; устаревшие файлы в обоих форматах удаляются. Установленный AU проходит
нативный auval и auval под Rosetta. Первый Rosetta-прогон после обновления
показывал старую версию 0.1.2 и ошибку открытия; повторная проверка видит 0.1.3
и завершается `AU VALIDATION SUCCEEDED` без изменения кода AU.

Финальный пакет заново проверяется после обновления этого отчёта и пересборки
архива исходников. Скрипт подготовки публикации работает локально по
умолчанию; публикация выполняется только с явным `--publish`.

Исходники и релиз подготовлены для публичного `ibotpafos/MConnect`.
До публикации репозитория/релиза запрос GitHub получает 404;
реальное уведомление о следующей версии требует опубликованного более
нового релиза. Проверка не меняет локальную передачу звука при офлайне.

Пакет использует ad-hoc подписи и не нотарифицирован Apple. Физические
iPhone/Android, отдельный Intel Mac и матрица разных DAW для 0.1.3 не
проверялись. Прежнее сообщение пользователя об успешной работе в студии
получено до этого изменения и не заменяет такую матрицу.

Локальные журналы: `test-results/updates-20261014/`. Они исключены из Git и
из распространяемых пакетов; в исходники входят сами тесты и процедуры.

```sh
ctest --test-dir build -C Release --output-on-failure
build/MConnectUpdateTests_artefacts/Release/MConnectUpdateTests --network
build/MConnectUpdateTests_artefacts/Release/MConnectUpdateTests --editor
python3 scripts/package_macos.py build
python3 scripts/release_github.py
```

Санитайзеры задаются для всех трёх языков через `CMAKE_C_FLAGS`,
`CMAKE_CXX_FLAGS`, `CMAKE_OBJCXX_FLAGS`; для ASan/UBSan используются
`-fsanitize=address,undefined -fno-omit-frame-pointer -fno-sanitize-recover=all`,
для TSan — `-fsanitize=thread -fno-omit-frame-pointer`.

Для браузерных тестов задайте `MCONNECT_PLAYWRIGHT` на установленный модуль
Playwright и `MCONNECT_TEST_TIMING_LIBRARY` на собранный
`build/libMConnectBrowserTiming.dylib`, затем выполните по очереди
`python3 tests/run_receivers.py` и `node tests/robustness.cjs`.
Тестовая библиотека таймеров и программный хост не поставляются пользователям.
