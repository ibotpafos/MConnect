# Проверка MConnect 0.1.4 — 2026-10-15

Среда: macOS 26.6.2, Apple Silicon, Apple Clang 21, universal arm64+x86_64.
DAW не запускалась. Использованы отдельное тестовое окно, pluginval и auval.

## Найденная проблема и исправление

При проверке опубликованного 0.1.3 настоящий HTTPS download дважды завершился
с NSURLError -1001 после сетевой паузы; контрольный curl получил только
10 076 345 из 20 714 774 байт за 180 секунд. Это наблюдение текущего сетевого
пути к GitHub, а не характеристика всех подключений. Неполный файл не был
предложен к установке. Повтор кнопкой работал, но требовал лишнего действия.

0.1.4 сохраняет короткие проверки метаданных (10/15 секунд), но допускает
60 секунд без данных и 600 секунд на попытку скачивания установщика. Есть
до двух автоматических повторов с прерываемым ожиданием 1 и 2 секунды.
Ошибки SHA-256 и постоянные HTTP-ошибки автоматически не повторяются.
Системные resume data передаются следующей попытке только в памяти;
Foundation восстанавливает файл, после чего проверяются его полный размер
и SHA-256. Если докачка невозможна, остаётся обычный ограниченный повтор.

Использован существующий URLSession, новая библиотека не добавляется.
Основание: [таймаут ожидания данных Apple](https://developer.apple.com/documentation/foundation/urlsessionconfiguration/timeoutintervalforrequest),
[докачка URLSession](https://developer.apple.com/documentation/foundation/pausing-and-resuming-downloads).

## Автоматические проверки

- Release CTest: core, updates, release_tool — PASS.
- Обновления под Rosetta x86_64 — PASS.
- ASan+UBSan и TSan для обновлений, с инструментированием C/C++/Objective-C++ — PASS.
- Восстановление после временных ошибок, максимум три попытки, передача resume
  data, отказ от повторов после 404 и неверного содержимого — PASS.
- Закрытие во время ожидания повтора: отмена менее 500 ms, новой попытки нет — PASS.
- Повреждённый/удалённый кеш, SHA, офлайн, ограничения метаданных и суточный кеш — PASS.
- Нативный HTTPS: GitHub 200, быстрая отмена и завершение callback queue — PASS.
  Обычный HTTP, сервер с самоподписанным TLS-сертификатом и ответ GitHub больше
  заданного лимита отклонены. Проверка текущей версии не предлагает откат
  на опубликованный 0.1.3 или повторную установку той же версии — PASS.
- 8 открытий/закрытий редактора — PASS; максимум около 47 ms в этом прогоне.
- VST3 pluginval 1.0.4, strictness 10, 48/192 kHz × 256/2048, repeat 2,
  random seeds 101504, 101505 и финальный 101506 — SUCCESS.

LeakSanitizer выключен; подавления санитайзеров не добавлялись.
Процессор, аудиозахват, WebRTC sender и телефонный JS побайтно
совпадают с опубликованным 0.1.3. В редактор добавлен только текст ошибки
свободного места. Предыдущая матрица браузеров и потоковых
проверок описана в [VALIDATION_0.1.3.md](VALIDATION_0.1.3.md); она не выдаётся
за повторный прогон для 0.1.4.

## Живой интерфейс и установщик

Выполнен отдельный живой прогон с публичным релизом 0.1.3. Для появления
уведомления тестовая цель компилирует настоящий редактор и updater как
старого клиента с константой версии 0.1.2. Это имитация версии: настоящий
выпуск 0.1.2 не имеет обновляющего кода. Фиктивный релиз не публикуется.
Хост не открывает аудиоустройство и не входит в распространяемый пакет.
Кеш пользователя временно изолируется и восстанавливается тестовым runner.

Автоматическое уведомление, один клик Download, прогресс, проверка полного
файла и SHA-256 — PASS. Первый запрос встретил системную POSIX-ошибку 28;
второй автоматически завершился. Всего около 634 секунд на текущем медленном
соединении, размер 20 714 774 байта, SHA-256
`c2f93197ad4488e80d22a474ff7954cb36f4131e31a99a1e03b99cd88a02a8bb`.
При ошибке 28 оставалось 8–9 GiB на системном диске и около 27 GiB на D:
причина этой ошибки не установлена, заполнение диска не подтверждено.
Файлы пользователя и настройки сети/безопасности не менялись.

В живом прогоне Foundation не предоставила resume data. Поэтому реальная
попытка использовала повтор с начала; перенос resume data проверен
контролируемым транспортом. Нативная ветка завершения HTTP 206 отдельно
на реальном сервере в этом прогоне не была вызвана.

Ready → повторная проверка → диалог — PASS. Кнопка Later отменяет переход;
повторное Open installer открывает системный Installer с точным путём
к скачанному файлу — PASS. Избыточный шаг согласия старого 0.1.3 отменён;
тот же скачанный файл установлен и переустановлен системной командой
installer, все файлы и удаление устаревших элементов проверены — PASS.

Пакет 0.1.4 проверен и реально установил обновление 0.1.3 → 0.1.4, затем
повторную установку. AU/VST3, обе архитектуры, подписи, соответствующие
исходники/лицензии и побайтовое содержимое установленного пакета — PASS.
В Distribution нет обязательного экрана согласия, копии лицензий в payload
проверены. Первые auval показывали кешированный номер 0.1.3; последующая
нативная проверка самостоятельно видит 0.1.4 и завершается успешно без
удаления системного кеша и остановки процессов.

После ручной разблокировки Mac завершён проход по кнопкам нового Installer
0.1.4 — PASS. Проверен точный путь к пакету: введение → «Продолжить» →
стандартная установка в папку пользователя → «Установить» →
«Установка успешно завершена» → «Закрыть». Обязательного экрана согласия
с лицензией и запроса пароля в этом прогоне не было. Проверка GUI выполняет
повторную установку 0.1.4; переход 0.1.3 → 0.1.4 проверен командой installer.
Уже работающие приложения не закрывались, DAW не запускалась.
Подготовка релиза отдельно проверяет содержимое пакета и SHA-256 всех активов;
архив исходников соответствует собираемому дереву файлов.

## Ограничения распространения

Плагины подписаны ad-hoc, установщик без Developer ID Installer и без
нотарификации. На этом Mac Gatekeeper уже отключён, действующих Developer ID
identities нет. Проверка здесь не подтверждает установку без предупреждений
на чужом Mac. Настройки безопасности в ходе проверки не менялись.
[Требования Apple](https://support.apple.com/en-us/102445).

Первую установку 0.1.3 или новее владельцам 0.1.2 нужно сделать вручную.
На медленном подключении 0.1.3 может потребовать ручную установку 0.1.4,
поскольку исправленный downloader начинает работать после обновления.
Физические телефоны, отдельный Intel Mac и Windows/Linux в этом прогоне
не проверялись.

до закрытия тестового окна: runner затем восстанавливает исходный кеш.

UBSAN_OPTIONS=halt_on_error=1:print_stacktrace=1,
TSAN_OPTIONS=halt_on_error=1:second_deadlock_stack=1.
