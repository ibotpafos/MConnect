# MConnect / Link 0.1.9

Выпуск от 2026-10-19 переносит повторную передачу и автоматический буфер
из проверенной локальной сборки в GitHub Releases и общий канал GD Connect.
DAW не запускается; установка и обновление проверяются в отдельных папках на D.

## Проверенная реализация

[RELIABLE_STREAMING.md](RELIABLE_STREAMING.md) и
[машинный отчёт](validation/reliable-streaming-2026-10-19.json) сохраняют девять
сетевых прогонов, четыре проверки восстановления, нагрузку и pluginval 10
предыдущей локальной сборки. Эти результаты относятся к указанным в отчёте
байтам и не выдаются за повторные измерения релизных файлов.

Релиз сохраняет native имя Link, производителя GD Connect, bundle ID
`audio.mconnect.plugin`, AU factory `MConnectAUFactory`, коды `Mcnn`/`Mcnt`
и все VST3 class IDs опубликованного пакета 0.1.8. Версия 0.1.9 компилируется
в исполняемый код, Info.plist и ответ `/info`; это не замена только метаданных.
Включён уже используемый редактор GD Kit 0.1.0 с закреплённым архивом исходников.

## Проверка выпуска

Перед публикацией обязательны:

- CTest, x86_64 core под Rosetta, pluginval 10 для окончательного VST3.
- Настоящий релизный VST3 в программном тестовом хосте: WebKit с потерями,
  задержкой и плохой сетью с момента подключения; повторное подключение.
- Настоящий AU через временную регистрацию factory только в тестовом процессе.
- AU/VST3 universal, минимум каждой архитектуры не выше macOS 11.0,
  неизменные идентификаторы относительно 0.1.8, постоянный сертификат GD Connect.
- PKG: текущий пользователь, локализация, корректные payload/версии/права,
  лицензии и соответствие встроенных исходников текущему Git.
- Native GD Connect: SHA-256/размер, установка, повторная установка,
  обновление с опубликованной 0.1.8, удаление в изолированной папке на D.
- Общий канал содержит все восемь продуктов; семь других ZIP переносятся
  побайтно. Для Link исправлено описание направления передачи: из DAW на телефон.
- После публикации: анонимный API и загрузка, проверка удалённых хэшей,
  обнаружение версии 0.1.9 обычным клиентом общего канала.

Результаты окончательных файлов, их SHA-256 и номера коммитов сохраняются
отдельным `release-verification.json` в GitHub Release. Локальные журналы —
`output/publish-0.1.9/`, подготовленный каталог — новый неизменяемый тег
`plugins-2026.10.19-mconnect-019`.

Для повторения упаковки после подписи собственных AU/VST3:

```sh
python3 scripts/package_macos.py build --preserve-signatures
python3 tests/installer.py dist/MConnect-0.1.9-macos-universal.pkg
python3 scripts/release_github.py
```

Без `--preserve-signatures` разработческая упаковка по-прежнему ставит ad-hoc
подпись. Существующие подписи при сохранении проверяются во всех архитектурах;
закрытые ключи в исходники и пакеты не включаются.

Постоянный тестовый сертификат не является Developer ID. Сборка не
нотарифицирована Apple. Поддерживаемый общий канал остаётся macOS 14+.
Safari на физическом iPhone отложен пользователем; автоматический WebKit
не заменяет эту проверку. Windows/Linux и физический Intel в этом выпуске
заново не проверялись.
